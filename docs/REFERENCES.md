# Primary references and related work

These are related methods, not endorsements or implementations vendored here.
The current public kernel is a Jacobi/Gauss–Seidel Gaussian linear-inference toy;
it is not presented as a full Gaussian belief-propagation implementation.

- Ori Shental, Danny Bickson, Paul H. Siegel, Jack K. Wolf, Danny Dolev.
  *Gaussian Belief Propagation for Solving Systems of Linear Equations: Theory
  and Application*. arXiv:0810.1119. https://arxiv.org/abs/0810.1119
- Rasmus Berg Palm, Ulrich Paquet, Ole Winther. *Recurrent Relational Networks*.
  arXiv:1711.08028. https://arxiv.org/abs/1711.08028
- Shaojie Bai, J. Zico Kolter, Vladlen Koltun. *Deep Equilibrium Models*.
  arXiv:1909.01377. https://arxiv.org/abs/1909.01377
- Sven Gowal et al. *On the Effectiveness of Interval Bound Propagation for
  Training Verifiably Robust Models*. arXiv:1810.12715.
  https://arxiv.org/abs/1810.12715
