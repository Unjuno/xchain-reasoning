# Stage 16–28: Belief–evidence mismatch and expected value

**Evidence level:** Historical report; not re-executed during this publication.

Nonlinear predictors improved where the earlier Ridge model had failed.
Observable R1 state added useful information beyond observations alone.

An initial mismatch signal used observations that the cropped model had not
actually received. Those results were removed from the main evidence. Restricting
the feature to internally accessible observations retained a smaller positive
effect. This distinction is essential for a fair internal scheduler.

Repeated R8 trajectories separated expected benefit from a lucky realized
success. Evidence contradiction scheduling exceeded the fixed R1/R8 binary
expected-compute hull by roughly 0.84 percentage points in the Stage 28 summary.

**Limit:** this was a binary-depth frontier, not the full R1/R2/R4/R8 frontier.
Instance oracles that know future sampling outcomes are not implementable
policies. Stage 29 tested stronger full-depth controls and found that cheap
readout correction and shallow restarts could explain important benefits.
